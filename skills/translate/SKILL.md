# 中英翻译规范

由 agent 直接翻译，不调用外部翻译服务。项目的 AGENTS.md、术语表或用户明确给的规则优先于本文件。

## 通用规则

1. 忠实原文：不增删、不总结、不加解释，也不加原文没有的限定或强调。下文的术语标注不算增删。
2. 不翻：公式、代码、命令、路径、URL、变量名、模型和数据集名、包名、配置键、方法缩写、引用键和引用编号。参考文献条目原样保留，只翻章节标题。
3. 结构不变：标题层级、列表、表格行列、图片位置、脚注、LaTeX 命令和标签。可见文字照常翻译，包括 `\section{}`、`\caption{}`、`\text{}` 的参数、链接文字、图片替代文字和表格里的说明文字；数字和单位不动。
4. 看不清或已损坏的符号和数值（如 `??`、乱码、缺失的公式）不按上下文猜：有原文 PDF 就对照原页，没有就原样保留。
5. 同一术语全文译法一致。术语表见 [glossary.md](references/glossary.md)。
6. 长文按章节逐段翻译并写入文件，不在对话里整篇输出。写完逐段核对没有漏译，重点检查否定、数字和单位、比较方向、条件和情态（如 may、must）。
7. 原文是文件且没指定输出位置时，译文写在原文旁边，英译中加 `_zh`、中译英加 `_en` 后缀；同名文件已存在时不覆盖，先问。图片链接改成从新位置能渲染的相对路径。
8. 交付时简短说明输出位置。看不清或损坏的内容、拿不准的术语、没译完的部分必须列出，不写进译文正文。

## 英译中

- 重要术语首次出现写成“中文译名 (English term)”，之后用中文或通用缩写。
- SFDA、SDDA 按原作者的写法分别用术语表里的译名，不自行互换，也不推断两者一定是不同任务。
- source domain、target domain、domain gap 等技术短语用“域”；泛指学科领域（如“计算机视觉领域”）仍用“领域”。

## 中译英

- 术语用该领域英文文献的通行说法，不按中文字面直译。拿不准时先查已有英文论文的用法，仍不确定就列为拿不准的术语。
- 缩写首次出现时，原文或上下文给出了全称就写成“全称 (缩写)”，之后只用缩写；全称不确定时不猜。
