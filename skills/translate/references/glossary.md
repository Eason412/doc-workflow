# 术语表

英译中、中译英共用。英文列是标准写法。查表时，原文里的大小写、单复数和拼写变体（如 adaption、labelling）视为同一个词。

| unsupervised domain adaptation | 无监督域自适应 | |
| source-free domain adaptation (SFDA) | 无源域自适应 | 原文写 source-free 时用 |
| source data-free domain adaptation (SDDA) | 源数据无关域自适应 | 原文写 source data-free 时用 |
| source-free open-set domain adaptation | 无源开放集域自适应 | |
| open-set domain adaptation | 开放集域自适应 | |
| closed-set domain adaptation | 闭集域自适应 | |
| partial domain adaptation | 部分域自适应 | |
| source domain | 源域 | |
| target domain | 目标域 | |
| domain shift | 域偏移 | |
| domain gap | 域差距 | |
| domain discrepancy | 域差异 | |
| domain-invariant | 域不变 | |
| domain-specific | 域特定 | |
| domain label | 域标签 | |
