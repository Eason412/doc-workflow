# 变更影响参考

以下用于定位可能受影响的正文，不是每次必须全改的清单。先确认项目中实际存在的 owner、消费者与本次授权范围。

| 改动 | 按需检查的说明 |
|---|---|
| API、路由或对外协议 | 接口说明、相关使用示例，以及确实受影响的调用方文档 |
| 环境变量、部署参数 | 配置说明、运维手册及需要用户设置这些值的入口 |
| 数据表或数据语义 | 数据模型说明、受影响的接口或恢复流程 |
| 用户流程 | 对应使用指南；README 只更新它实际承载的入口信息 |
| 架构或依赖变化 | 相应架构说明与必要的迁移说明 |
| 已交付行为或长期决定 | 项目要求的变更记录或决策 owner，不复制到所有文档 |
| 记忆中的过期或冲突事实 | 先核对来源；只有明确获准时按宿主记忆机制提交修正 |

同一事实保留一份正文，其他位置用引用连接。对外使用方式、内部原理和运维步骤服务不同读者，只在相应信息确实改变时更新。

跨项目依赖不自动扩大写入范围。可确定受影响但未获准修改的项目，报告具体文件与建议。历史决策保留取代关系和必要证据，不为了消除关键词或相对时间而删除历史。
