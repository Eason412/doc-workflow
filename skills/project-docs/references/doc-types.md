# 其他文档类型

写接口文档、运维手册、架构说明或上手指南时读本文；README 见 [README 写法](readme.md)。以下栏目是按需选用的清单，不是固定模板，项目里没有的内容不写、不编。

改编自 [anthropics/knowledge-work-plugins](https://github.com/anthropics/knowledge-work-plugins) 的 engineering/documentation（Apache-2.0）。

## 接口文档

- 每个接口给出请求与响应示例，示例从测试或实际调用核对。
- 认证方式、错误码及其含义。
- 限流、分页与超时等调用约束。
- 有 SDK 或客户端时给调用示例。

## 运维手册

- 适用时机：什么现象或任务下打开这份手册。
- 前提：需要的权限、账号、工具与环境。
- 逐步操作，每步写明命令和预期结果。
- 回滚步骤；出问题时找谁、怎么升级处理。

## 架构说明

- 背景与目标：要解决什么问题，有哪些约束。
- 整体结构：组件、它们之间的关系，配图或文字描述。
- 关键决定与取舍：选了什么、放弃了什么、为什么；已有选型记录时引用，不复制。
- 数据流与外部对接点。

## 上手指南

- 环境搭建：从零到能跑起来的步骤。
- 关键系统及其如何连接。
- 常见任务的完整走查。
- 遇到哪类问题找谁。

## 共同要求

- 先确定读者和他要完成的事，最有用的信息放最前。
- 能给命令、代码和截图的地方不只用文字描述。
